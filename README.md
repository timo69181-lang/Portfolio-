# Mustafa Ali — 3D Event & Exhibition Designer

A personal portfolio website showcasing 3D event and exhibition design work — commercial exhibition booths, experiential environments, and CGI visualization across Saudi Arabia and the GCC.

## Pages

- **Home** (`index.html`) — Hero, about summary, featured works, and featured products
- **About** (`about.html`) — Designer statement and services
- **Career** (`career.html`) — Experience and professional timeline
- **Works** (`works.html`) — Full project gallery
- **Project detail** (`project.html`) — Individual project pages (e.g. `?id=huawei`)
- **Clients** (`clients.html`) — Brands and clients

## Tech

- Plain HTML, CSS (`css/styles.css`), and vanilla JS (`js/main.js`, `js/projects.js`)
- Google Fonts (Inter) and Font Awesome icons via CDN
- No build step or framework — open `index.html` directly or serve the folder

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8080
```

The site is designed for GitHub Pages — push to the repository root and enable Pages from the `main` branch. Live URL:
